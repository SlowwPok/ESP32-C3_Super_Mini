система працює на esp32-c3
живлення з піна 5v від MT3608 DC-DC Step-Up Converter на який йде напруга з Модуль заряду Li-Ion акумулятора ( на мс EM4056A, із захистом ) Type-C

буде в себе включати: 
  ESP32-C3 SuperMini
  Барометр/термометр/датчик влажности на чипе BME280
  1.9 Inch TFT Display HD Screen SPI ST7789 320х170
  Датчик температуры DS18B20 (18B20) цифровой
  Часы реального времени DS1307 + EEPROM 24C32 32K
  Датчик освещенности GY-302 на чипе BH1750
  2 шт - NeoPixel линейка 8 RGB LED WS2812 с адресацией
  2 шт - Сенсорная кнопка / датчик прикосновения TTP223 мини
  Датчик газа MQ-135 модуль

всі сенсори та датчики для збору інформації:

  Датчик температуры DS18B20 (18B20) цифровой
  Часы реального времени DS1307 + EEPROM 24C32 32K
  Датчик освещенности GY-302 на чипе BH1750
  Датчик газа MQ-135 модуль

Сенсорні кнопки для керування:
  Одна дисплеем (перемикання екранів)
  Одна для Ленти та її режимів

RGB ленти 2 шт
  для освітлення та ефектів

Зараз йде робота з Екраном та Лентами і 1 сенсорною кнопкою котра керує живленням екрану та лент
і коли все увімкнено то вона перемикає режими лент
Екран у свою чергу вмикається і вимикається по тій же логіці що й ленти
При зміні режиму лент на екран виводиться інформація про поточний режим, його налаштування, назву та кольори (показ їх) для обох лент

Бажана архітекрута проекту:
  ESP32-C3_SUPER_MINI
    >include/ - системна
    >legacy/ - для файлів та коду який не використовується в проекті зараз
      >debug/ - папка з файлами для дебагу дисплея на бібліотеці LovyanGFX (вона поточна)
      >display_AdafruitGFX/ - папка з файлами бібліотеки Adafruit GFX для дисплея (не використовується)
    >lib/ - системна
    >src/ - корін проекту та коду
      >controls/
        >controls.cpp/h - керування всіма кнопками і т д. опрацьовування будь-яких натисканнь і т д.
      >display/
        >LovyanGFX/
          >ui/
            >display_ui.cpp/h - тут відображається весь інтерфейс, вся інформація
          >display_LovyanGFX_config.h - налаштування пінів, та дисплею
          >display_LovyanGFX.cpp/h - створення методів малювання на дисплею, функцій та відображення
      >system/
        >system_state.cpp/h - збір данних про систему та всі модулі та сенсори, стан чи увімкнені, які режими і т.д. перевірка помилок ініціалізації та відправка в серіал монітор інформації про статус системи, або збір данних для виводу на дисплей оскільки цей модуль опрацьовує та збирає всю системну інформацію, від увімкнена система та коли вона увімкнулась, до деталей, наприклад який зараз активни режим світлодіодної ленти та його налаштування.
      >main.cpp - основний файл де викликаються всі ініціалізації та функції, він має бути найчистіший, тут нічого не реалізовується
      >resourses/ - додаткова папка для зберігання ресурсів додаткових для модулів чи шрифтів
        >colors/
          >color_palette.h - бібліотека кольорів для використання в rgb ленті, чи на дисплеї, для зручності користування та чистого коду, використання назв кольорів а не їх кодів.
      >RGB_strip/ - відповідає за ленти
        >rgb_strip.cpp/h - основний файл який збирає все до купи і змушує працювати
        >rgb_config.h / - налаштування, кількість лент, піни, кількість світлодіодів
        >rgb_modes.cpp/h - бібліотека режимів роботи лент, кольори, налаштування режимів, щоб зручно додавати та віднімати їх, тут нічого не реалізується
        >rgb_animation_engine.cpp/h - реалізація анімацій та їх бібліотека
      >sensor_BME280/
        >BME280_config.h - налаштування, піни і т д
        >BME280.cpp/h - збір данних сенсора та відправка в систему, реалізація його роботи
      >sensor_DS18B20_18B20/
        >DS18B20_18B20_config.h - налаштування, піни і т д
        >DS18B20_18B20.cpp/h - збір данних сенсора та відправка в систему, реалізація його роботи
      >sensor_DS1307_eeprom_24c32_32k/
        >DS1307_eeprom_24c32_32k_config.h - налаштування, піни і т д
        >DS1307_eeprom_24c32_32k.cpp/h - збір данних сенсора та відправка в систему, реалізація його роботи
      >sensor_GY-302_BH1750/
        >GY-302_BH1750_config.h - налаштування, піни і т д
        >GY-302_BH1750.cpp/h - збір данних сенсора та відправка в систему, реалізація його роботи
      >sensor_MQ-135/
        >MQ-135_config.h - налаштування, піни і т д

    >test/ - системна

UI побудований за екранно-віджетною моделлю:
Кожен екран UI — це окремий віджет
Віджет повністю інкапсулює:
свою логіку
стан
побудову даних
малювання
Центральний display_ui не містить логіки екрану, а лише:
керує power / sleep
малює header / footer
викликає активний екран
Дисплейний драйвер (display_LovyanGFX) не знає нічого про UI, режими, RGB, анімації тощо.
